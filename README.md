# Final-Group-Project---EAS-4610
This repository holds the components of the EAS 4610 Final Group Project. The project members are Kaelyn Young and Sandra Hernandez. This repository will include a README, a Rough Notebook, and the Final Notebook. 

Our project topic is 1D Tsunami Propagation. It is based on Kowalik's 2012 paper, "Introduction to Numerical Modeling of Tsunami Waves," Chapter II.

Our notebook contains the following sections: Introduction, Equations, Numerical Methods, Results, Discussion, Figures, and References. 

The notebooks are Jupyter Notebooks in ipynb format, using Python in Google Colab.
